# 项目 2 简历文案

定位：**多模态服务拆分、跨阶段通信与特征复用**。项目 1 体现引擎内部 KV、调度和 GPU 执行优化，这里集中写服务边界、数据交接和复用。

## 当前可用的三条

**xixi-server | 多模态三阶段推理服务**　2026.06 - 2026.09

基于 ModServe 开源实现扩展，使用 PyTorch、Transformers、SmolVLM、Gloo/NCCL 与 HTTP/SSE。

- 将视觉编码与投影、Prefill、Decode 拆为独立进程与可配置设备池，实现空闲副本路由、阶段槽位释放及有界并发背压；支持单图/多图、纯文本旁路与 HTTP/SSE。
- 实现 Gloo 元数据/确认与 NCCL CUDA 张量通道，将多层 KV 按固定顺序打包交接；以请求身份、形状校验和 ACK 管理特征/KV 生命周期，处理取消、超时与工作进程退出。
- 实现按图片内容寻址的字节级视觉特征 LRU，支持同图不同问题、部分命中和多图重排；构建单模型对照、通信探针与冷热图片消融，验证生成一致性并保存逐请求记录。

这版描述已经实现的代码。本机已验证单卡/Gloo 的真实模型路径及单卡 NCCL API；真实三卡 P2P 验收尚待完成，不把三卡配置或跳过用例写成已完成的部署效果。
